1. 环境准备

  • 已安装 conda 与常用库（pandas、numpy、scikit-learn、matplotlib、seaborn）。
  • 安装GNN所需依赖：pip install torch torch_geometric
  • 激活环境：conda activate DM
  • 确保实验代码文件与 实验二数据集.csv 在同一目录。

3. 关键原理速览

  • PCA（主成分分析）：线性降维方法，通过正交变换将高维数据投影到低维空间，保留数据的主要方差信息，缓解维度灾难。
  • K-Means：划分型聚类算法，通过迭代更新簇中心，使簇内相似度最大化，簇间相似度最小化；需要预先指定簇数，适合球形簇。
  • DBSCAN：基于密度的聚类算法，通过识别高密度区域来划分簇，能够自动识别噪声点，无需预先指定簇数，适合任意形状的簇。
  • K近邻图构建：基于余弦相似度计算样本间的相似性，为每个样本选择最相似的K个样本作为邻居，构建无向图结构。
  • GCN（图卷积网络）：利用图结构信息，通过卷积操作提取节点特征，能够捕获样本间的关系，适合图数据的分类任务。
  • MLP（多层感知机）：传统的深度学习模型，仅使用节点特征进行分类，忽略样本间的结构信息，作为GCN的基线模型。
  • 轮廓系数：评估聚类效果的指标，综合考虑簇内紧密度和簇间分离度，取值范围为[-1,1]，越大表示聚类效果越好。
  • 调整兰德指数（ARI）：衡量聚类结果与真实标签一致性的指标，取值范围为[0,1]，越大表示聚类结果与真实标签越一致。
  • ROC曲线与AUC：评估分类模型性能的指标，ROC曲线是真阳性率（TPR）和假阳性率（FPR）的关系曲线，AUC是ROC曲线下的面积，越大表示模型性能越好。
  • PR曲线与AUC：评估分类模型性能的指标，PR曲线是精确率（Precision）和召回率（Recall）的关系曲线，AUC是PR曲线下的面积，越大表示模型性能越好。

4. 参数与可调项

4.1 数据预处理与降维

  • pca_components：PCA降维后的主成分数量，默认50，可根据需要调整。
  • missing_value_strategy：缺失值处理策略，默认均值填充，可选择中位数填充或删除。
  • scaler：特征标准化方法，默认StandardScaler，可选择MinMaxScaler等。

4.2 聚类算法

K-Means

  • n_clusters：簇的数量，默认5（对应5种样本类型），可根据实际数据分布调整。
  • random_state：随机种子，用于控制初始化的随机性，默认42。
  • max_iter：最大迭代次数，默认300，可根据需要增加以确保收敛。

DBSCAN

  • eps：邻域半径，默认300（根据距离图斜率突变点确定），对聚类结果影响显著。
  • min_samples：邻域内最少样本数，默认5，可根据数据密度调整。
  • metric：距离度量方法，默认欧氏距离，可选择余弦相似度等。

4.3 图构建

  • n_neighbors：K近邻图的邻居数量，默认10，可根据样本数量调整。
  • similarity_metric：相似度计算方法，默认余弦相似度，可选择欧氏距离等。

4.4 分类模型

GCN

  • hidden_channels：隐藏层通道数，默认64，可根据模型复杂度调整。
  • lr：学习率，默认0.01，可选择0.001或0.1等。
  • epochs：训练轮数，默认100，可根据模型收敛情况调整。
  • weight_decay：权重衰减，默认0.001，用于防止过拟合。

MLP

  • hidden_channels：隐藏层通道数，默认64，与GCN保持一致以便对比。
  • lr：学习率，默认0.01，与GCN保持一致以便对比。
  • epochs：训练轮数，默认100，与GCN保持一致以便对比。
  • weight_decay：权重衰减，默认0.001，与GCN保持一致以便对比。
